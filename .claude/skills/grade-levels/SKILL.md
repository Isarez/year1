- **ระดับชั้น (`GRADES` ใน `js/data-cats-*.js`, branch `feature/grade-levels`)**: หมวดที่มี `cat.grade` ('p1'/'p2'/'p3') จะโชว์เฉพาะตอนเลือกชั้นนั้นในแถบ `renderGradeBar()` (หมวดที่ไม่มี `grade` = ชุดเตรียม ป.1 เดิมทั้งหมด) แยก id/progress/สติกเกอร์ต่อชั้นเสมอ ห้ามใช้ id ซ้ำข้ามชั้น
  - **icon ของหมวด ป.2/ป.3 ครบทุกหมวดแล้ว** (`assets/icons/p2-*.svg`, `p3-*.svg` — 1 หมวด 1 ไฟล์ ตั้งชื่อไฟล์ตาม cat id): สไตล์เดียวกับ icon เดิม (viewBox 0 0 64 64, เงาใต้ภาพ, gradient `#g`, เส้นขอบหนา) + **ป้ายวงกลมบอกระดับชั้นมุมล่างขวา ("ป.2"/"ป.3")** ถ้าเพิ่มหมวดใหม่ของชั้นเหล่านี้ต้องวาด icon + ป้ายชั้นให้เข้าชุดเสมอ (หมวดข้ามชั้นที่ใช้ engine เดียวกันให้เปลี่ยนสี/รายละเอียดไม่ให้ icon เหมือนกันเป๊ะ)
  - **โจทย์ยึดหลักสูตรแกนกลางของชั้นนั้น** — ป.1 ไม่มีคูณ/หารและจำนวนเกิน 100, คำควบกล้ำ/อักษรนำเป็นของ ป.2-3, การเทียบโน้ตสากล C-D-E เป็นของ ป.3 ขึ้นไป, ราชาศัพท์เป็นของ ป.5-6 (เคยหลุดมาอยู่ ป.1/ป.3 แล้วแก้ออกเมื่อ 2026-07-28) — โจทย์ `tier:3` ของ ป.3 ตั้งใจให้เป็นเนื้อหาเร่งชั้นถัดไป (ป.4) ได้ แต่ห้ามเกิน 1 ชั้น
- **ระดับชั้น ป.4 (เปิดใช้งานแล้ว — `GRADES` p4 `available:true`)**: 41 หมวด = quiz 21 (คลังละ 21-23 ข้อ `poolPick:10` สัดส่วน tier 1/2/3 ≈ 9/9/5) + AR 4 + ฟังคำ 2 + เกมทักษะ 14 — โจทย์อิงตัวชี้วัด ป.4 (จำนวนเกินแสน-ล้าน, คูณ-หารหลายหลัก, เศษส่วน-ทศนิยม-มุม-พื้นที่, ชนิดของคำ 7 ชนิด-คำเป็นคำตาย-สำนวน, Present Simple, สุโขทัย-ภูมิศาสตร์-เศรษฐศาสตร์, การจำแนกสิ่งมีชีวิต-แรง มวล แสง ดวงจันทร์, ระบบสุริยะ) โดย `tier:3` = เนื้อหาเร่ง ป.5 เท่านั้น
  - AR ป.4 ใช้ `sentenceLens:[5,6,7]` → ต้องมีคลัง `AR_SENTENCES[lang][7]` (เพิ่มแล้วทั้ง th/en อย่างละ 12 ประโยค) — ถ้าจะทำ ป.5-6 ให้เติมบัคเก็ตใหม่ก่อนเสมอ
  - คลัง sort ใหม่ของ ป.4 ใน `SORT_POOLS`: `vertebrate` (สัตว์มี/ไม่มีกระดูกสันหลัง), `thaiword` (คำนาม/กริยา/วิเศษณ์), `angletype` (มุมแหลม/ฉาก/ป้าน)
- **mechanic ใหม่ของ ป.4 — 3 engine ใหม่ (view + logic ของตัวเอง, ดาว/ผลลัพธ์ผ่าน `finishP2Game` เหมือนเกมทักษะอื่น)**:
  1. `mode:'chart'` "อ่านแผนภูมิแท่ง" (`#chart-view`, `startChartGame`) — สุ่มชุดข้อมูลจาก `CHART_SETS` (5 ชุด) ค่าของแต่ละแท่ง **ไม่ซ้ำกัน** เพื่อให้คำถาม "มากที่สุด/น้อยที่สุด" มีคำตอบเดียว, คำถามไล่ระดับตามด่าน (max/min/value → +total → diff/more)
  2. `mode:'area'` "พื้นที่ตารางหน่วย" (`#area-view`, `startAreaGame`) — ด่าน 1-4 ระบายให้ครบจำนวนตารางหน่วย (รูปอิสระ), ด่าน 5-10 ต้องระบายเป็นสี่เหลี่ยมผืนผ้าตามกว้าง×ยาว (ตรวจด้วย `areaIsRectangle()` ต้องเต็มกรอบพอดี ไม่มีรู วางแนวไหนก็ได้)
  3. `mode:'angle'` "มุมมหัศจรรย์" (`#angle-view`, `startAngleGame`) — ลากจุดจับรอบจุดยอด snap ทีละ 5° ยอมรับคลาดเคลื่อน ±2°, มีเส้นไกด์ทุก 15° (`buildAngleGuides`) และส่วนโค้งแสดงขนาดมุม — **ถ้าเพิ่ม view ใหม่ในอนาคต ต้องเพิ่ม `chartView`/`areaView`/`angleView` ในทุกจุดที่ซ่อน view ด้วย** (ทั้ง 3 ตัวถูกเติมไว้ทุกจุดที่มี `coordView.hidden` แล้ว)
