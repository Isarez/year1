- **เกมฟังประโยคเติมคำ (`cloze-view`, `type:'listen'` + `mode:'cloze'`)** — เพิ่มเมื่อ 2026-07-29, **เป็นภาษาอังกฤษล้วนทุกหมวด** (ปรับจากเดิมที่มีเวอร์ชันไทยด้วย เมื่อ 2026-07-29 ตามคำขอผู้ใช้ — **ห้ามใส่ประโยคภาษาไทยกลับโดยไม่ถาม**) มี **ชั้นละ 2 เกม รวม 10 หมวด** (เตรียม ป.1 / ป.1 / ป.2 / ป.3 / ป.4) โชว์ใน section "เกมฟังคำและประโยค" (`#cat-grid-listen`)
  - กลไก: เครื่องอ่านออกเสียง **ทั้งประโยครวมคำที่หายไป** (auto 1 ครั้งตอนขึ้นด่าน + ปุ่ม 🔊 กดซ้ำได้) แต่บนจอเว้นช่องว่าง 1-2 ช่อง เด็กแตะการ์ดคำมาเติม (แตะช่องที่เติมแล้วเพื่อเอาออก) เติมครบตรวจอัตโนมัติ — ตอบผิดคืนเฉพาะช่องที่ผิด ช่องที่ถูกค้างไว้ให้ (นับ 1 พลาด)
  - คลังประโยค `CLOZE_SETS` = **en1-en5 ชุดละ 30 ประโยค รวม 150 ประโยค** ไล่ความยาวเฉลี่ย 4.0 → 5.0 → 6.0 → 7.0 → 8.0 คำ (en1 = เตรียม ป.1 … en5 = ป.4) แต่ละประโยคเก็บเป็น `{t:[โทเคน], b:[index ที่เว้นได้], e:emoji}` **`b` ต้องมีอย่างน้อย 2 ตำแหน่ง** และ **คำในตำแหน่งที่เว้นได้ห้ามซ้ำกันเองในประโยคเดียว**
  - เกม 1 กับเกม 2 ของแต่ละชั้น **ใช้ชุดประโยคเดียวกัน** แต่ต่างกันที่ `cat.clozeBlanks` (จำนวนช่องว่าง) และ `cat.clozeDecoys` (จำนวนการ์ดหลอก) ทั้งคู่เป็น `[ด่าน 1-4, 5-8, 9-10]` เช่น ป.4: เกม 1 = `[1,2,2]/[4,4,5]`, เกม 2 = `[2,2,2]/[4,5,5]`
  - ตัวหลอกสุ่มจาก "คำที่เว้นได้ของประโยคอื่นในชุดเดียวกัน" จึงเป็นชนิดคำใกล้เคียงกันอัตโนมัติ (ไม่ต้องมีคลังตัวหลอกแยก)
  - engine เก็บ **card element ต่อช่อง** (`clozeGame.filledCard[pos]`) ไม่ map ด้วยคำ — กันพังถ้าอนาคตมีการ์ดคำซ้ำกัน (บทเรียนเดียวกับ engine ฟังคำฝั่งโหมดครู)
  - **id ของ 2 หมวดชุดเตรียม ป.1 ยังเป็น `cloze-th1`/`cloze-th2`** (คงไว้เพราะผูก progress/สติกเกอร์เดิม) แม้เนื้อหาจะเป็นภาษาอังกฤษแล้ว — ห้ามเปลี่ยน id
  - อ่านออกเสียงด้วย `speakClozeSentence()` ต่อโทเคนด้วยช่องว่าง (อังกฤษ) และใช้กติกา `cancel()+speak()` ใน user gesture เหมือน `speakListenWord` (ห้ามหน่วง setTimeout)
- **ความยากของคำในเกมฟังคำ ผูกกับระดับชั้นผ่าน `cat.wordLens`** (เพิ่มเมื่อ 2026-07-28): `[ยาวช่วงด่าน 1-4, 5-8, 9-10]` อ่านด้วย `listenWordLen(cat, level)` ใน `js/games-listen.js / js/games-write.js` — **`LISTEN_WORDS` (อังกฤษ) เปลี่ยนจาก array แบนเป็น object บัคเก็ตตามจำนวนตัวอักษร 3/4/5/6/7 แล้ว** (เดิมมีแต่คำ 3 ตัวอักษรใช้ร่วมกันทุกชั้น) และ `LISTEN_WORDS_TH` เพิ่มบัคเก็ต 6/7 ตัวอักษร
  - ค่าปัจจุบัน: เตรียม ป.1 = en [3,3,4]/[3,4,4], th [3,4,5]/[4,4,5] · ป.1 = en [3,4,4], th [4,4,5] · ป.2 = en [3,4,5], th [4,5,5] · ป.3 = en [4,5,5], th [4,5,6] · ป.4 = en/th [5,6,7]
  - **กติกาคลังคำ: ตัวอักษรในคำเดียวกันห้ามซ้ำกันเอง** (ทั้งไทยและอังกฤษ) เพราะ engine ใช้ตัวอักษรเป็น key ของการ์ด (`listenGame.cardEls`) — มีสคริปต์ตรวจใน commit นี้ ถ้าเพิ่มคำใหม่ต้องเช็คทั้ง "ยาวตรงบัคเก็ต" และ "ตัวอักษรไม่ซ้ำ"
  - จำนวนการ์ดรวมถูกจำกัดไม่เกิน 9 ใบเสมอ (คำยิ่งยาว ตัวหลอกยิ่งลดอัตโนมัติ) และจำนวนตัวเฉลย (mode `hint`) ปรับตามความยาวคำ โดยเหลือให้เด็กหาเองอย่างน้อย 2 ตัว
  - **ป.3 มีเกมฟังคำแล้ว** (`p3-listen-en` 📻 / `p3-listen-th` 📢) เพิ่มเข้ามาเพื่อไม่ให้บันไดความยากขาดช่วงระหว่าง ป.2 กับ ป.4
- **คลังคำโยงเส้น AR แยกตามระดับชั้นได้ด้วย `cat.matchSet`** — `AR_MATCH_ITEMS` เพิ่มคลัง `enAdv` (คำศัพท์ยาว 6-10 ตัวอักษร เช่น Butterfly/Helicopter) ใช้กับ `p4-eng-match` ส่วน ป.1-3 ยังใช้ `th`/`en` เดิม
- **เกมฟังคำ (`listen-view`, `type:'listen'`)**: `listen1`/`listen2` (คำอังกฤษ, คลัง `LISTEN_WORDS`) และ `listen-th1`/`listen-th2` (คำไทย 3-5 ตัวอักษร, คลัง `LISTEN_WORDS_TH` แยก 3 ระดับความยาว) แยก pool ด้วย `cat.lang` ใน `renderListenLevel()` → `prepareListenLevelEn`/`prepareListenLevelTh` — ตัวอักษรไทยที่ยืนเดี่ยวไม่ได้ (สระบน/ล่าง/วรรณยุกต์) **โชว์เป็นตัวอักษรดิบๆ ตรงๆ ไม่มี prefix ใดๆ** (เคยลองใช้ "o" เป็นฐานแล้วเอาออกหลังทดสอบจริงเพราะดูไม่เหมาะ — **ห้ามใส่ "o" กลับโดยไม่ถาม**) — `speakListenWord()` เช็ค voice ภาษาไทยผ่าน `hasThaiVoiceSupport()`/`pickThaiVoice()` เพื่อ set `u.voice` ตรงๆ และโชว์สัญลักษณ์คำใบ้ (`#listen-symbol`) เสริมถ้าตรวจไม่เจอ voice ไทย แต่**ไม่บล็อกการพูดจริง**อีกต่อไป (เคยบล็อกแล้วเจอบั๊กเสียงไม่ออกเพราะตรวจ false negative ได้ง่าย) — **สำคัญ: ต้องเรียก `speechSynthesis.cancel()`+`speak()` ตรงๆ ในจังหวะที่ผู้ใช้กดปุ่ม (user gesture) ห้ามหน่วงด้วย `setTimeout` เด็ดขาด** เพราะ iOS Safari (iPad — อุปกรณ์หลักของแอป) จะบล็อกเสียงถ้า `speak()` ไม่ได้อยู่ใน user gesture โดยตรง = กดฟังแล้วเงียบ (เคยหน่วง 30ms เพื่อกันบั๊ก Chrome แต่ทำให้ iPad ไม่มีเสียง — เอาออกแล้วเมื่อ 2026-07-27, ทดสอบ Chrome เรียกตรงๆ ทำงานปกติทั้งกดเดี่ยว/รัวๆ) — ใช้กติกาเดียวกันกับ `speakClockText` (เกมนาฬิกา) และ `speakTeacherWord` (โหมดครู)
- **เกมลากเส้นต่อจุด (`dots-view`, `type:'write'`, section "เกมฝึกเขียน" `#cat-grid-write`)**: `write-dots1` ✏️ (easy 5-7 จุด) / `write-dots2` 🖍️ (hard 10-13 จุด, ล็อกผ่าน `CAT_REQUIRES` dots1→dots2) — คลัง `DOTS_SHAPES` ใน `js/data-pools.js` อย่างละ **30 รูป** สุ่ม 10 รูปต่อรอบ (`startDotsGame`: shuffle+slice ตาม `cat.levels`) พิกัดจุดระบบ 0-100 ตรงกับ SVG viewBox ของ `#dots-svg` (กระดาน `.dots-stage` เป็นจัตุรัส `aspect-ratio:1/1` เสมอ จึงไม่ต้องแปลงพิกัด) — **กติกาการวางจุดในรูปใหม่: จุดติดกันห่าง ≥12 หน่วย จุดใดๆ ห่าง ≥10 หน่วย พิกัดอยู่ใน 3-97** ไม่งั้นวงรับสัมผัสซ้อนกันกดพลาดง่าย
  - **mechanic ลากเท่านั้น (ห้ามเปลี่ยนกลับเป็นแตะโดยไม่ถาม)**: กดจุด 1 ค้างแล้วลากเส้นตามลำดับเลข แตะเฉยๆ ไม่ต่อจุด ปล่อยนิ้วกลางทางแล้วจับจุดล่าสุด (anchor สีเขียว) ลากต่อได้ ลากรวดหลายจุดไม่ยกนิ้วได้ ลากโดนจุดผิด (รัศมี `DOTS_WRONG_R` แคบกว่า `DOTS_HIT_R`) = mistake จุดสั่นแดง เส้นชั่วคราวแฟลชแดงแล้วหาย **ไม่มี highlight บอกใบ้จุดถัดไป** (เอาออกตามคำขอผู้ใช้) ครบทุกจุดระบบปิดเส้นกลับจุด 1 อัตโนมัติ + เฉลย (`#dots-fill` เติมสี + `#dots-reveal` emoji/ชื่อรูป z-index เหนือจุด + `.dots-stage.revealed` จางจุดลงไม่ให้บังเฉลย) ดาวเกณฑ์ mistakes เดิม (0→3, ≤4→2, else→1)
  - ข้อควรระวัง: เส้นชั่วคราว `#dots-temp` เป็น **SVG `<line>` ซึ่งไม่มี property `.hidden`** (มีเฉพาะ HTMLElement) ต้องใช้ `setAttribute('hidden','')`/`removeAttribute('hidden')` เท่านั้น (เคยเป็นบั๊กเส้นไม่โชว์มาแล้ว); `body.dots-open` (ตั้งใน `startDotsGame` ถอดใน `renderHome`/`finishDotsGame`/switch-child) ย่อ `.owl-widget` หุบมุมบนจอ ≤768px เพราะนกฮูก fixed มุมขวาล่างเคยบังจุดแถวล่างจนแตะไม่ได้; กระดานกว้าง `min(94vw,66vh,620px)` และ ≥1025px เป็น `min(94vw,76vh,760px)`; `renderHome` โชว์ progress ด้วย `Math.min(p.best,total)` กัน best เก่าเกิน total ใหม่
