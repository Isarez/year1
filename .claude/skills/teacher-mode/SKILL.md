- **โหมดคุณครู (`teacher/`, เฟส 1)**: หน้าแยกให้ครู/ผู้ปกครองสร้างชุดโจทย์เอง เข้าผ่าน `owlkids.net/teacher` เท่านั้น — setup ครั้งแรก (ชื่อครู+โรงเรียน+avatar ชุดเดียวกับหน้าหลัก), **หน้า home โชว์เฉพาะเกมที่ publish แล้ว**: ปุ่มเลือกระดับชั้น (`.grade-chip` เฉพาะชั้นที่มีเกม publish) + เกมจัดกลุ่มเป็น section ตามรูปแบบเกม (mechanic) แบบหน้าหลัก การ์ดใช้ `.cat-card` เดิม **ไม่มีปุ่มย่อยบนการ์ด คลิกทั้งใบ = เข้าเล่นเลย**, ปุ่ม "จัดการโจทย์" เปิด `#manage-view` (list ทุกชุดรวม draft พร้อมปุ่ม เผยแพร่/แก้ไข/ลบ — ลบมี modal ยืนยัน), ฟอร์มสร้างเกม (`#builder-view`): ระดับชั้น/mechanic (เฟส 1 เปิดแค่ quiz ตัวอื่น disabled "เร็วๆ นี้")/ชื่อเกม/logo 12 แบบ/จำนวนโจทย์ต่อรอบ (สุ่มจาก pool ได้)/โจทย์+คำตอบหลายช่อง (radio ติ๊กข้อถูก)/checkbox สุ่มสลับ/save draft หรือ publish (publish พากลับ home, draft กลับหน้าที่มา — `builderFrom`), เล่นด้วย quiz engine ที่ adapt มา (ดาวตามเกณฑ์ pct 0.9/0.6 เดิม) **จบเกมไม่มีสติกเกอร์**, footer ไม่มี privacy note (ตามคำขอ) มี visitor badge (hitscounter.dev — ดูกติกา dev/prod ในหัวข้อ Visitor badge ด้านบน) + Buy me a Milk + ปุ่ม "รายละเอียดการอัพเดท" (`#changelog-open-btn`) บนสุด footer (สไตล์ `.child-import-btn.changelog-open-btn` เหมือนหน้าหลัก) — **version/changelog แยกจากฝั่งเด็ก**: อ่าน `teacher/version` + `teacher/changelog` เอง (เริ่ม v1.17.0, footer แสดง "vX (teacher)", คลิกเลข version ก็เปิด changelog ได้), `parseChangelog()` port มาจาก app.js. **แนบรูปประกอบโจทย์ได้เฉพาะ mechanic `quiz`** (`attachQuizImageControl`/`compressQuizImage` ใน `teacher.js`): ย่อรูปด้วย canvas ≤560px + เพดาน ~90KB/รูป (ลดคุณภาพก่อนแล้วค่อยลดขนาดวน), เก็บ `question.img` เป็น JPEG data URL (ไป export/import อัตโนมัติ), ในฟอร์มพรีวิวรูปอยู่**เหนือช่องโจทย์**เหมือนตอนเล่นจริง (ปุ่มลบต่อท้ายรูป + ข้อความแจ้งเตือนใต้ปุ่มเพิ่มรูป), ตอนเล่นแสดง `#q-image` เหนือคำถาม, `saveGames()` คืน bool + rollback ถ้า quota เต็ม
  - **เฟส 3 (ฟังคำศัพท์)**: `teacher/teacher-listen.js` (โหลดหลัง `teacher-ar.js`) — mechanic `listen` ("ฟังคำศัพท์ สะกดคำ", `form:'words'`) engine port จาก `js/games-*.js ฝั่งเด็ก` คง id/class `.listen-*` (view `#listen-view` ใน `teacher/index.html`, reuse CSS จาก `css/style.css`) — ฟอร์ม: 1 ข้อ = 1 คำ + ปุ่ม 🔊 ลองฟัง (`speakTeacherWord` เดาภาษาไทย/อังกฤษจากตัวอักษรในคำ) + ช่องรูปใบ้ emoji (โชว์ตอนเล่นเฉพาะเมื่อเครื่องอ่านออกเสียงคำนั้นไม่ได้) + checkbox `#b-listen-hint` เฉลยตัวอักษรช่วย (แถว `#b-listen-hint-row` โชว์เฉพาะ form 'words', เก็บเป็น `game.listenHint`) — validation: คำเดียวไม่เว้นวรรค 2-8 ตัวอักษร ห้ามปนไทย+อังกฤษ อังกฤษเก็บตัวพิมพ์เล็ก — **ข้อแตกต่างที่ตั้งใจจาก engine เด็ก (อย่า sync กลับ)**: `filled[pos]` เก็บ card element ตรงๆ แทน map ด้วยตัวอักษร เพราะคำครูมีตัวอักษรซ้ำในคำได้ (เช่น book) ขณะที่คลังคำหน้าเด็กคัดไม่ให้ซ้ำ, ตัวอักษรลวงสร้างอัตโนมัติ (pool ไทย `LISTEN_TH_DECOYS` ก็อปจาก `THAI_DECOY_CHARS` เพราะ teacher ไม่โหลด data.js / อังกฤษ a-z, การ์ดรวม ≤9 ใบ) — จำนวนโจทย์ต่อรอบ = จำนวนด่าน (การ์ด/หน้าจัดการโชว์ "ด่าน" ผ่าน `['pairs','words']`), `lastPlay.type='listen'` — **ถ้าเพิ่ม view ใหม่ฝั่ง teacher ต้องเพิ่มทั้งใน `showView` array (teacher.js) และจุดซ่อน view ใน `startTeacherAR` (teacher-ar.js)** — ลำดับ chip: quiz → AR 4 แบบ → listen → match → mix → music (ทุกตัว `enabled:true` มี engine ครบแล้ว)
  - **เฟส 4 (match/mix/music)**: 3 mechanic ใหม่กลุ่มทักษะ ใช้ engine port จาก `js/games-*.js ฝั่งเด็ก` คง id/class/CSS เดิม โหลดต่อจาก `teacher-listen.js` — `match` ("จับคู่ความจำ" 🎴, `form:'pairs'`, `teacher/teacher-match.js`, view `#memory-view`, reuse `.memory-*`), `mix` ("ผสมสี" 🎨, `form:'mix'`, `teacher/teacher-mix.js`, `#mix-view`, reuse `.mix-*`), `music` ("ดนตรี" 🎹, `form:'music'`, `teacher/teacher-music.js`, `#music-view` reuse `.music-*`) — ครูสร้างโจทย์เอง: match ใส่คู่ที่เข้ากัน (`form:'pairs'` เดียวกับ ar-connect), mix ตั้งสูตรผสมสี, music กดเปียโนจิ๋วแต่งทำนอง (`buildMusicBlock` ใน `teacher.js`, เก็บ index คีย์ขาว, **2-30 โน้ต/ทำนอง**) — dispatch เล่นที่ `playTeacherGame()` (`startTeacherMatch`/`startTeacherMix`/`startTeacherMusic`), จุดซ่อน view ใน `startTeacherAR` (`teacher-ar.js`) เพิ่ม `memoryView`/`mixView`/`musicView` แล้ว, จบเกมไม่มีสติกเกอร์เหมือน mechanic อื่นฝั่งครู
  - **เฟส 2 (AR)**: `teacher/teacher-ar.js` (โหลดหลัง `teacher.js`) — AR engine ที่ **port มาจาก `js/games-*.js ฝั่งเด็ก` แบบคง id/class/CSS เดิมทั้งหมด** (ar-view/ar-card/ar-slot/ar-match-* ฯลฯ ใช้สไตล์จาก `css/style.css` ตรงๆ) เปิด mechanic 4 แบบ: `ar-pick` (mode math — โจทย์+การ์ดคำตอบจากฟอร์ม choices เดียวกับ quiz), `ar-order`/`ar-sentence` (mode sentence — เรียงการ์ดใส่ช่อง), `ar-connect` (mode match — โยงเส้น สุ่มครั้งละ ≤4 คู่ ต้องมี ≥2 คู่ถึง publish ได้) — mechanic แต่ละแบบมีฟอร์มใส่โจทย์ของตัวเอง (`mech.form`: choices/sentence/order/pairs) สลับ mechanic ในฟอร์มแล้ว re-render พื้นที่โจทย์ (`renderQuestionArea()`), การเล่น dispatch ที่ `playTeacherGame()` (quiz → quiz engine, AR → `startTeacherAR()`), ปุ่มทำอีกครั้งใช้ `lastPlay` — **ถ้าแก้ engine AR ของหน้าหลัก (`js/games-*.js ฝั่งเด็ก`) ให้พิจารณา sync การแก้เข้า `teacher/teacher-ar.js` ด้วยเสมอ** (โค้ด copy กันมา ไม่ shared — มี subagent `engine-sync-checker` ช่วยเทียบ drift ได้) ข้อแตกต่างที่**ตั้งใจ**ให้ต่างจากโหมดเด็ก: `renderMatchPairs` ฝั่ง teacher ใช้ `matchLabelClass()` เลือก class ป้ายตามเนื้อหาจริงทั้งสองฝั่ง (emoji ล้วน → `.ar-match-emoji`, มีตัวอักษร/ตัวเลข → `.ar-match-word`) เพราะคู่ของครูเป็นข้อความอิสระ ไม่ใช่ emoji เสมอแบบโหมดเด็ก — อย่า "sync กลับ" ให้เหมือน app.js, หัว section บนหน้า home ครูใช้ icon SVG ชุดเดียวกับหน้าหลัก (`section-quiz/ar/skill/listen.svg`), icon โรงเรียน `assets/icons/teacher/school.svg`, logo เกมมี 24 แบบ, การ์ด/รายการมี fade-in ไล่จังหวะ (`.tg-fade` + `tgFadeUp` ใน teacher.css) ตอนกด filter
  - **แก้ไขโปรไฟล์ (เด็ก/ครู)**: หน้าหลัก `#edit-emoji-modal` (เปิดจากปุ่มดินสอ `#header-edit-emoji-btn` คู่กับชื่อเด็กใน header หรือปุ่มดินสอคู่กับการ์ดเด็กแต่ละคนหน้าเลือกโปรไฟล์) แก้ได้ทั้ง avatar และ**ชื่อ** (เดิมแก้ได้แค่ avatar, title modal เปลี่ยนจาก "เลือก avatar ใหม่" เป็น "แก้ไขโปรไฟล์") เช็คชื่อซ้ำกับเด็กคนอื่นเหมือนตอนสร้างโปรไฟล์ (ไม่สนตัวพิมพ์เล็ก/ใหญ่) — โหมดคุณครูมีปุ่มดินสอ `#teacher-edit-btn` คู่กับ chip ชื่อครูใน header (คลิก chip เองก็เปิดได้เหมือนกัน) เปิด `#teacher-edit-modal` แก้ชื่อ/โรงเรียน/avatar ครูได้เช่นกัน (ไม่มีเช็คชื่อซ้ำเพราะมีครูคนเดียวต่อเครื่อง)
  - **Toast notification (`.toast` ใน `css/style.css`) ต้องมี z-index สูงกว่า modal ที่อาจเปิดทับอยู่เสมอ** — เคยตั้งไว้ z-index:160 ต่ำกว่า modal ทุกอัน (200 หน้าหลัก / 300 โหมดคุณครู) ทำให้ toast (เช่น แจ้งชื่อซ้ำตอนแก้โปรไฟล์) โผล่หลัง modal มองไม่เห็นตอน modal เปิดอยู่ แก้เป็น z-index:320 (สูงกว่า modal ทุกอันทั้ง 2 หน้าเว็บ) — ถ้าเพิ่ม modal ใหม่ที่ z-index สูงกว่านี้ในอนาคตต้องดัน `.toast` ให้สูงกว่าเสมอ
