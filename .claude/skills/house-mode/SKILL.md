# โหมด "บ้านของหนู" (3D)

⚠️ **ก่อนแตะโค้ดโหมดบ้านทุกครั้ง ต้องอ่าน [`QUEST-DESIGN.md`](../../../QUEST-DESIGN.md) หัวข้อ "⭐ สรุปบริบท" ให้จบก่อน**
(กติกาเหล็ก 7 ข้อ + ข้อที่ผู้ใช้ล็อกแล้วห้ามเปลี่ยนเอง) และอ่านข้อ 40-43 ที่บันทึกว่าเฟส 5-9 ทำอะไรต่างจากแผน

## โครงสร้างไฟล์หลังแยกไฟล์รอบ 2026-08-12 (refactor)

หลังทำครบ 9 เฟส `js/house.js` โตเป็น 13,622 บรรทัด จึงแยกออกเป็นไฟล์ย่อย (พฤติกรรมไม่เปลี่ยน):

| ไฟล์ | บรรทัด | หน้าที่ |
|---|---|---|
| `js/house.js` | ~11,670 | ระบบเกม: ลูปวาด · การเดิน · เควสต์ · ตกแต่ง · สัตว์เลี้ยง · ประกอบร่างฉาก |
| `js/house-models.js` | 979 | โมเดลตึก/ร้านค้า + ชิ้นส่วนสถาปัตยกรรม (หลังคา/ประตู/หน้าต่าง/ป้ายร้าน) |
| `js/house-avatar.js` | 1,066 | ตัวละคร: ทรงผม/ตา/ลายเสื้อ/เครื่องหัว/แว่น/เป้/ของถือ/รองเท้า + `buildCharacter` |

| `js/house-quests.js` | ~1,950 | engine เควสต์ (กลไก 40+ · สุ่มรายวัน · รางวัล · ประตูความพร้อม) |
| `js/house-pet-toys.js` | ~640 | **ของเล่นสัตว์เลี้ยง (เฟส 12.1)** — โมเดล 3D + ท่าเล่นของน้อง + ท่าของเด็ก ชิ้นละชุด |

⚠️ **ทั้ง 3 ไฟล์ที่แยกออกมาใช้รูปแบบเดียวกับ `house-furniture.js`**: ประกาศ `HOUSE_XXX(kit)` แล้ว
`house.js` ดึงกลับมาเป็นชื่อเดิมทุกตัวด้วย destructure ⇒ โค้ดเดิมไม่ต้องแก้ · **ต้องโหลดก่อน `house.js` เสมอ**
(ลำดับคุมที่ `js/games-ar.js`)

⚠️ **กับดักที่เจอตอนแยก (พลาดมาแล้ว 2 รอบ)**: `hShadows` ฝั่ง `house.js` เป็น `let` ที่ตั้งค่า
**ทีหลัง**ตอน `initThreeCore` ⇒ ส่งเข้า kit ต้องส่งเป็น **ฟังก์ชัน** ถ้าส่งเป็นค่าจะได้ `false`
ค้างตลอด = ไม่มีเงาทั้งเกมโดยไม่มี error ให้จับ (syntax check ผ่านฉลุย)

⚠️ **`buildStaticScenery`/`buildWorld` ไม่ได้แยกออกมาโดยตั้งใจ** — วัดแล้วเรียกฟังก์ชันอื่น 82 ตัว
เป็นตัวประกอบร่างฉากทั้งเมือง ย้ายแล้วต้องส่ง context มหาศาลจนอ่านยากกว่าเดิม
